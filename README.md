# CLAWVERSE · 星际抓娃娃

一个纯前端的网页版抓娃娃小游戏。娃娃机使用 Canvas 2D 实时 3D 投影绘制，可以从 **正面 / 右侧 / 背面 / 左侧** 四个方向观察机器内部，再配合相机方向移动爪子、落爪抓取。

## 运行方式

不需要安装依赖，直接双击 `index.html` 用浏览器打开即可。

如果浏览器对本地文件限制较多，也可以在当前目录启动一个静态服务器：

```powershell
npx serve .
# 或者
python -m http.server 8080
```

然后访问终端里给出的地址。

想让朋友直接玩：见 [deploy.md](deploy.md) 里的公开链接、局域网分享和文件发送方案。

## 操作

| 操作 | 键盘 | 屏幕 |
| --- | --- | --- |
| 移动爪子 | `W` `A` `S` `D` / 方向键 | 拖动左下角摇杆 |
| 落爪 | `Space` | 点击右下角「落爪」 |
| 旋转到四个视角 | `Q` / `E`，或 `1`–`4` | 点击右侧视角按钮 |
| 暂停/玩法说明 | — | 右上角 `?` |

移动方向会跟随当前视角：无论转到哪一面，`W` 都是朝屏幕里侧，`A/D` 是左右。

## 手机端

- 已适配手机竖屏布局：触摸拖动左下摇杆移动，点击右下大按钮落爪，顶部四个按钮切换视角。
- 刘海屏安全区、底部手势条、高 DPI 屏幕都已处理；横屏空间会比较紧，建议竖屏游玩。
- 手机访问时，把整个 `claw-machine` 文件夹放到手机可访问的静态服务器，或传到手机后用浏览器打开其中的 `index.html`。

## 玩法

- 初始有 10 枚游戏币，每次落爪消耗 1 枚。
- 地面准星越绿，代表爪子与目标的距离越近，抓取成功率越高。
- 抓中娃娃会获得积分，并奖励 2 枚游戏币；娃娃会通过取物口进入底部展示窗。
- 集齐 7 款娃娃（棕熊、兔兔、企鹅、鸭鸭、橘猫、星星、涂鸦鸡）即可通关。
- **涂鸦鸡**是手绘稀有款：白底黑色涂鸦、头顶两个圈、圈圈翅膀和火柴腿，60 分，抓力较低。
- 如果游戏币用完，会出现结算界面，可以重新开始。

## 技术说明

- 纯 HTML / CSS / JavaScript，没有任何第三方依赖。
- 自行实现的透视投影与相机绕轨：四向切换是平滑绕机器旋转，不是四张静态背景图。
- 娃娃、爪子和机柜全部用 Canvas 绘制，支持高 DPI 和移动端触控。
- 音效使用 Web Audio API 实时合成，可静音。
- 最高分保存在 `localStorage`（在部分浏览器直接打开本地文件时可能不可用，会自动忽略）。
